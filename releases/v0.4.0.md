# Phyllotaxis v0.4.0

## What's New

- **Auto-detect output format:** When stdout is piped, phyllotaxis now defaults to JSON output — no `--json` flag needed. Terminal sessions still get human-readable text. Use `--text` to force text output when piped, or `--json` to force JSON at a terminal. This makes LLM tool-use integration seamless: `phyll --resources | jq .` just works.

- **Remote URL support:** Fetch OpenAPI specs directly from HTTP/HTTPS URLs. Pass a URL anywhere you'd pass a file path — as a positional argument, via `--doc`, or through `PHYLLOTAXIS_DOCUMENT`. Downloaded specs are cached locally at `~/.cache/phyllotaxis/` and reused on subsequent runs. Use `--refresh` to force a re-download.

  ```bash
  phyll https://petstore3.swagger.io/api/v3/openapi.json
  phyll --doc https://api.example.com/openapi.yaml --resources
  phyll https://api.example.com/spec.json --refresh  # bypass cache
  ```

## Bug Fixes
- None

## Breaking Changes
- None. `--json` continues to work as before. Local file paths are unchanged.

## Upgrade Notes
- Binary size increased from ~1.6MB to ~4.7MB due to the addition of `reqwest` (HTTP client) and `rustls` (TLS). This is a one-time cost that enables future HTTP features.
- New dependency: `reqwest` 0.12 with `blocking` + `rustls-tls` features
- New dependency: `sha2` 0.10 for cache key generation
- Two new licenses allowed in `deny.toml`: `BSD-3-Clause` and `CDLA-Permissive-2.0` (from TLS/crypto dependencies)
